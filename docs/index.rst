NeuronSphere Homebrew Tap
=========================

This repository is a `Homebrew Tap <https://docs.brew.sh/Taps>`_ that
distributes NeuronSphere command-line tools as pre-compiled binaries.

Install anything here in one command:

.. code-block:: bash

    brew install neuronsphere/tap/bartleby

The tools ship as casks, so Homebrew installs them on macOS only. On Linux,
use the release tarballs or build from source.
